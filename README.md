# SupportFlow — Service Request Management Dashboard

**Portfolio type:** Personal/demo project  
**Technologies:** HTML5, CSS3, JavaScript, LocalStorage

SupportFlow is a responsive service-request dashboard built as a portfolio demonstration. It models the kind of internal tool a small support team could use to track requests, priorities, statuses, and queue health.

## Features
- Responsive desktop, tablet, and mobile dashboard
- Search and multi-filter request queue
- Create-request modal with client-side validation
- Live status updates
- Summary KPI cards and dynamic status distribution chart
- LocalStorage persistence
- CSV export
- Dark/light theme persistence
- Accessible labels, semantic HTML, keyboard-friendly dialog
- Zero external dependencies

## Run locally
Open `index.html` in a modern browser.

## Portfolio disclosure
This is a personal demonstration project. The example support requests, users, ratings, and operational data are fictional and are included only to demonstrate product functionality.


## Mobile responsiveness
Tested for narrow mobile layouts. The sidebar becomes an off-canvas menu, controls stack cleanly, and the request table scrolls inside its own panel rather than causing page-level horizontal overflow.
