# SupportFlow QA Checklist

- [ ] Dashboard loads without console errors
- [ ] KPI totals match request data
- [ ] Search filters by ID, title, category, priority, and status
- [ ] Status filter works
- [ ] Priority filter works
- [ ] Quick filters work
- [ ] Reset filters restores the full queue
- [ ] New request form rejects invalid input
- [ ] Valid request is added to the top of the queue
- [ ] New request persists after browser refresh
- [ ] Status changes persist after refresh
- [ ] CSV export downloads a valid file
- [ ] Dark/light theme persists after refresh
- [ ] Layout works at desktop width
- [ ] Layout works at tablet width
- [ ] Layout works at mobile width
- [ ] Modal can be used with keyboard controls
- [ ] Mobile sidebar opens and closes correctly
